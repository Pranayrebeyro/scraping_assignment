# AI Usage

## Overview

AI assistance was used during the development of this Python web scraping assignment as a development and review aid.

The final implementation was reviewed, tested, and verified locally before being considered complete.

AI was mainly used for:

- Understanding the assignment requirements
- Planning the project structure
- Discussing implementation approaches
- Reviewing scraping and processing logic
- Troubleshooting Python environment and test issues
- Improving documentation
- Checking edge cases and validation logic

---

## AI Tools Used

ChatGPT was used during development.

The AI was used as an assistant rather than as a replacement for testing or verification.

---

Examples of prompts used during development include:

### Project Planning
